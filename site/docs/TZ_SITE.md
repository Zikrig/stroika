# ТЗ: демонстрационный веб-интерфейс (каталог `site/`)

## Назначение

Локальные PHP-страницы для демонстрации экранов, аналогичных Telegram-боту, **без подключения к боту и к прод-БД**. Данные — JSON в `site/data/`, изменения в браузере — `localStorage` (ключ `stroika_demo_v1`).

## Структура

| Путь | Описание |
|------|----------|
| `index.php` | Старт, переключение роли |
| `cards_chairman.php` | Таблица заявок + фильтры (JSON + merge) |
| `chairman_dashboard.php` | KPI-сводка |
| `request.php` | Карточка заявки, история, вложения, действия руководителя (демо) |
| `foreman_requests.php` | Список заявок прораба (demo user id=10) |
| `foreman_new.php` | Мастер создания заявки |
| `pdo_queue.php` / `pdo_request.php` | Очередь ПДО и обработка (в т.ч. имитация дробления) |
| `proc_queue.php` / `proc_request.php` | Очередь закупки и действия |
| `admin_users.php` | Пользователи из `users.json` |
| `assets/app.css`, `assets/app.js` | Общие стили и демо-слой |
| `layout/header.php`, `nav.php`, `footer.php` | Шапка и навигация |
| `inc/data.php` | Загрузка JSON |
| `data/*.json` | Демо-данные |

## Роли

Переключатель в шапке (`?role=chairman|foreman|pdo|procurement|admin`). Без реальной авторизации.

## Демо-слой

`app.js` объединяет базовый JSON с объектом из `localStorage`: правки заявок, новые заявки, новые события. Сброс: кнопка на `request.php` или очистка `localStorage`.

## Дальнейшая интеграция (не входит в демо)

Подключение к SQLite/API бота, сессии, загрузка файлов на сервер, парсинг Excel на бэкенде — отдельный этап.
