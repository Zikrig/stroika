# Демо-сайт (PHP + JSON + JS)

Откройте в браузере `index.php` из этого каталога (через встроенный PHP-сервер или Apache/Nginx).

```bash
cd site
php -S localhost:8080
```

Документация: [docs/TZ_SITE.md](docs/TZ_SITE.md).

Данные: `data/*.json`. Локальные демо-изменения: `localStorage` ключ `stroika_demo_v1`.
