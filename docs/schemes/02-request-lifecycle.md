# Схема 2: Жизненный цикл одной заявки (шаги 1–9)

Полный пример заявки **IG-24** от создания прорабом до закрытия или отмены. Каждый шаг — отдельное событие в группе (новое сообщение с полным паспортом и динамическим блоком).

Эмодзи в динамическом блоке считаются частью стандарта: `👤` Ответственный, `📦` Потребность, `🚚` Закупка, `📍` На объекте. Цветовой маркер статуса (`🟡`, `🔵`, `⚪`, `⚫`) также обязателен по этапу.

---

## Шаг 1 — Прораб создал заявку

**Действие:** Прораб в боте написал, что нужно, и заполнил поля: количество, цель, срок.

**В группе:** Бот публикует сообщение с паспортом (прораб Тимиров, объект Игора, цель Забор, номенклатура «Сетка рабица 23а/22», 2000 м, требуется до 01.03.2026) и динамическим блоком.

| Элемент | Значение |
|---------|----------|
| Статус | Ожидает обработки |
| Этап | Создано |
| Ответственный | ПДО |
| Запрошено / Со склада / В закупку | 2000 м / — / — |
| На объекте | Получено: 0 м, Остаток: 2000 м |

---

## Шаг 2 — ПДО нажал «К заявке»

**Действие:** ПДО нажал «К заявке»; бот выгрузил Excel с ID IG-24.

**В группе:** Публикуется новое сообщение по той же заявке.

| Элемент | Значение |
|---------|----------|
| Статус | В работе |
| Этап | Excel выдан, ожидается загрузка формы |
| Ответственный | ПДО |
| Потребность | без изменений |

---

## Шаг 3 — ПДО загрузил Excel

**Действие:** ПДО загрузил заполненный Excel (250 м со склада, 1750 м в закупку).

**В группе:** Новое сообщение; паспорт без изменений, обновлён динамический блок и цифры движения.

| Элемент | Значение |
|---------|----------|
| Статус | Ожидает обработки |
| Этап | Передано в закупку |
| Ответственный | Закупка |
| Запрошено / Со склада / В закупку | 2000 м / 250 м / 1750 м |

---

## Шаг 4 — Закупка нажала «К заявке»

**Действие:** Закупка в группе нажала «К заявке» (вход в процесс по заявке).

**В группе:** Новое сообщение.

| Элемент | Значение |
|---------|----------|
| Статус | В работе |
| Этап | Закупка в работе |
| Ответственный | Закупка |
| Потребность | 2000 / 250 / 1750 м (без изменений) |

---

## Шаг 5 — Закупка нажала «Закуплено»

**Действие:** Закупка нажала «Закуплено» и ввела ожидаемую дату отгрузки: 22.02.2026.

**В группе:** Новое сообщение.

| Элемент | Значение |
|---------|----------|
| Статус | В работе |
| Этап | Закуплено |
| Ответственный | Закупка |
| Ожидаемая дата отгрузки | 22.02.2026 |
| Дата отгрузки / поставки на объект | — / — |

---

## Шаг 6 — Закупка нажала «Отгружено»

**Действие:** Закупка нажала «Отгружено» и ввела ожидаемую дату поставки на объект: 24.02.2026 (фактическая дата отгрузки в примере: 20.02.2026).

**В группе:** Новое сообщение; ответственный переходит к прорабу.

| Элемент | Значение |
|---------|----------|
| Статус | Передано дальше |
| Этап | Отгружено поставщиком |
| Ответственный | Прораб |
| Ожидаемая дата отгрузки / Дата отгрузки / Поставка на объект | 22.02.2026 / 20.02.2026 / 24.02.2026 |
| На объекте | Получено: 0 м, Остаток: 2000 м |

---

## Шаг 7 — Получено частично (прораб)

**Действие:** Прораб нажал «Получено частично» и ввёл количество: 1500 м.

**В группе:** Новое сообщение; обновлены «На объекте» и этап.

| Элемент | Значение |
|---------|----------|
| Статус | Получение (или аналог по вашей легенде) |
| Этап | Получено частично |
| Ответственный | Прораб |
| На объекте | Получено: 1500 м, Остаток: 500 м |

---

## Шаг 8 — Получено полностью (прораб)

**Действие:** Прораб нажал «Получено полностью».

**В группе:** Новое сообщение; заявка закрывается.

| Элемент | Значение |
|---------|----------|
| Статус | Завершено |
| Этап | Получено полностью |
| Ответственный | — |
| На объекте | Получено: 2000 м, Остаток: 0 м |

---

## Шаг 9 — Пример отмены

**Действие:** Любая роль, у которой есть право отмены на текущем этапе (например, ПДО до передачи в закупку), нажимает «Отменить» и вводит комментарий.

**В группе:** Новое сообщение с полным паспортом и динамическим блоком.

| Элемент | Значение |
|---------|----------|
| Статус | Отменено |
| Этап | Отменено ПДО (или «Отменено прорабом» / «Отменено закупкой» по факту) |
| Ответственный | — |
| Комментарий | Обязательный текст, например: «Ошибка в заявке, созвонились с прорабом — будет новая заявка» |
| Потребность (итог) | Со склада: 0, В закупку: 0, Остаток: 0 |

Заявка после отмены закрыта навсегда и уходит в архив.
