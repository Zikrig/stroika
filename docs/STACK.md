# Стек технологий: Бот заявок (aiogram + Docker)

Краткое описание технологий и окружения для разработки и эксплуатации бота системы учёта заявок.

---

## 1. Ядро приложения

### 1.1 Python

- **Версия**: 3.11+ (рекомендуется 3.12).
- **Назначение**: основной язык бота и всех воркеров/скриптов.

### 1.2 Aiogram

- **Версия**: aiogram 3.x (async).
- **Назначение**: работа с Telegram Bot API (Long Polling или Webhook).
- **Используется для**:
  - приём сообщений и файлов в группах;
  - отправка сообщений с паспортом и динамическим блоком;
  - инлайн-кнопки под сообщениями (callback);
  - разграничение доступа по ролям (middleware / FSM при необходимости);
  - привязка действий к заявке по `message_id` или `callback.message.message_id` + ID заявки в БД.

### 1.3 База данных

- **Рекомендация**: PostgreSQL (удобно для событийной истории и отчётности).
- **Альтернатива**: SQLite — для старта или малых объёмов.
- **Хранение**:
  - заявки (паспорт, текущий этап, статус, ответственный);
  - события по заявкам (для истории в чате и выгрузки в Google);
  - привязка групп к объектам и роли пользователей по группам;
  - контейнеры и связь дочерних заявок с родительским ID.
- **ORM**: SQLAlchemy 2 (async) или asyncpg — по предпочтениям команды.

## 2. Интеграции

### 2.1 Google Таблица (сквозной журнал)

- **API**: Google Sheets API v4.
- **Аутентификация**: Service Account (JSON-ключ), либо OAuth2 для доступа к конкретным таблицам.
- **Действия**: только добавление строк (append); редактирование/удаление строк ботом не выполняется (таблица = неизменяемый лог).
- **Библиотека**: `gspread` с асинхронной обёрткой или `google-api-python-client` + `google-auth`.
- **Данные строки**: см. раздел «Структура записи в Google Таблице» в DESIGN.md.

### 2.2 Парсинг Excel (формализация ПДО)

- **Формат**: .xlsx от ПДО с полями по регламенту (ID, согласовано, даты, подобъект, прораб, наименования, код 1С, запрошено, ед. изм., со склада, в закупку).
- **Библиотека**: `openpyxl` для чтения .xlsx.
- **Логика**: проверка «Запрошено = Со склада + В закупку»; генерация контейнера и дочерних заявок при нескольких строках; подстановка ID ботом.

## 3. Окружение и развёртывание

### 3.1 Docker

- **Образ**: один образ на основе `python:3.12-slim` (или alpine при необходимости экономии места).
- **Сервис**: один контейнер с процессом бота (aiogram Long Polling или worker для webhook).
- **Том/переменные**:
  - конфиг (токен бота, путь к JSON Google, ID таблицы и листа);
  - при использовании SQLite — volume для файла БД;
  - при PostgreSQL — подключение через переменные окружения (DATABASE_URL и т.п.).

### 3.2 Docker Compose (рекомендуется)

- **Сервисы**:
  - `bot` — приложение aiogram.
  - `postgres` — БД (если используется PostgreSQL).
- **Сеть**: общая внутренняя сеть; бот подключается к БД по имени сервиса.
- **Секреты**: токен бота, ключ Google Service Account вынести в `.env` или Docker secrets, не хранить в репозитории.

### 3.3 Переменные окружения (пример)

```env
BOT_TOKEN=...
DATABASE_URL=postgresql+asyncpg://user:pass@postgres:5432/requests_db
GOOGLE_CREDENTIALS_PATH=/run/secrets/google_sa.json
GOOGLE_SHEET_ID=...
GOOGLE_SHEET_LIST=Лист1
LOG_LEVEL=INFO
```

## 4. Вспомогательные технологии

### 4.1 Логирование

- `logging` или `structlog`; вывод в stdout для сбора логами Docker.
- Уровень задаётся через `LOG_LEVEL`.

### 4.2 Конфигурация

- Предпочтительно: переменные окружения + один конфиг-модуль (pydantic-settings или dotenv).
- Не хранить токены и ключи в коде.

### 4.3 Запуск

- Точка входа: например `main.py` или `bot/__main__.py`.
- Команда в контейнере: `python -m bot` или `python main.py`.
- При падении процесса — перезапуск через Docker (restart: unless-stopped) или оркестратор (systemd, k8s).

---

## 5. Краткая схема стека

```
[ Telegram ]  <--->  [ Aiogram 3 (Python 3.11+) ]
                            |
                            +---> [ PostgreSQL / SQLite ]
                            +---> [ Google Sheets API ]
                            +---> [ openpyxl — Excel ]
                            |
                     [ Docker / Docker Compose ]
```
